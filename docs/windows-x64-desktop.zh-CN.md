# OpenPulse Windows x64 桌面候选包

版本：0.2.2-candidate.1。仅为本地验收候选包，尚未公开发布；不代表分析器 0.2.2 已正式发布。

## 解压和启动

适用 Windows x64。将整个 ZIP 解压到有写入权限的本地目录，打开 `OpenPulse` 文件夹，双击 `OpenPulse.exe`。支持中文和空格目录。不要只复制 exe，必须保留 `app`、`runtime`、许可证和说明文件。

随包包含私有 Java 21 / JavaFX 运行环境和真实 C++ 分析器。使用时无需安装 Java、Maven、C++ 编译器、数据库，也无需启动服务器。首次运行同样不需要下载依赖。构建此包所需的开发工具不属于用户运行前提。

本候选包未签名。请核对可信来源提供的 SHA-256；遇到 Windows 来源提示时先核实文件来源，不要关闭系统保护。校验可在 ZIP 所在目录运行：

```powershell
Get-FileHash .\OpenPulse-0.2.2-candidate.1-windows-x64.zip -Algorithm SHA256
```

将结果与同名 `.zip.sha256` 文件比较。版本和实际运行环境见 `VERSION.json`，包内文件清单见 `FILES.sha256`。

## 完成一次分析

1. 点击“选择文件夹”，选择本地项目；也可在路径框粘贴完整路径。
2. 点击“开始分析”。窗口保持响应，默认超时 30 秒。需要中止时点击“取消”，等待清理完成后可重新分析。
3. 在“概览”查看项目、文件/语言统计及结构事实；在“发现与证据”选择发现，查看证据和修复建议；在“扫描限制”查看未覆盖或跳过的内容。
4. 点击“导出 JSON”保存报告，再用“打开 JSON”重新查看。只接受通过正式 Schema 和语义校验的 v2 报告；旧协议、格式错误、未知字段及大于 16 MiB 的报告会被拒绝。
5. 关闭窗口即可退出；正在分析时关闭会先终止子进程并清理临时文件。

分析、导入和导出均在本地进行，没有登录、云端 AI、网站、历史数据库或自动更新。报告会包含项目路径及扫描所得事实，请自行选择保存和分享位置。报告导入不会修改路径框；重新分析前核对所选项目。

## 理解结果

桌面显式使用协议 2.0，随包 CLI 默认仍是 1.0。成功、零发现或检测到测试文件，都不能证明代码无缺陷或测试已通过。扫描限制是报告内容的一部分，部分完成会持续提示。

导出保留已校验的协议事实，不保证空白排版与原 JSON 字节相同。没有后台服务；关闭后不会保留扫描历史或项目选择。

## 遇到问题

- 无法启动：确认系统为 Windows x64，完整解压，`runtime` 未被移走或安全软件隔离。不要用开发目录中的 JAR 代替 exe。
- 找不到分析器：检查 `app/bin/openpulse-analyzer.exe` 是否保留。不要从其他版本随意补文件。
- 分析失败或超时：按提示核对目录权限，选择较小项目重试；清理失败会另行明确提示。
- 无法保存：更换有写入权限的位置，检查文件占用及磁盘空间。
- 无法打开 JSON：确认它是完整的 v2 原始报告，不要手工删字段绕过校验。
